## 作品简介

这个世界，天上飞着蒸汽飞艇，地下爬着触手怪物。
修仙？那是把血肉换成冰冷的齿轮！
求神？那是将灵魂喂给深渊的恶鬼！

穿越成破落商人之子的炎冬，在停尸房醒来，脑内多了一个【诡枢录】。
系统转换，一念为人，一念为诡！

当巡检司追杀魔门诡修，炎冬正用机械臂擦拭嘴边的诡异血迹；
当深渊邪神降临世间，炎冬正用真气驱动着核动力阵法。

你以为我是正道之光？其实我诡异入骨。
你以为我畸变堕落？其实我机械飞升！
在这疯狂的世界，唯有比诡异更诡异，比疯子更疯子，才能活到最后！

## 核心主题

> **"比诡异更诡异，比疯子更疯子，才能活到最后。"**

本书的内核不是"正义战胜邪恶"，而是"在疯狂的世界里，找到自己的活法"。三条主题线贯穿全书：

1. **修仙即修诡**——无论正道魔道，修炼的本质都是接触诡异源质。正道把血肉换成齿轮，魔道把灵魂喂给恶鬼，两条路的尽头都是"非人"。炎冬的械诡双修打破了这个二元对立
2. **秩序比混乱更残忍**——道庭以"净化"之名行"喂养"之实，凡人交的净化税最终变成高层机械神仙的燃料。正道比魔道更黑暗，因为它用秩序包装剥削
3. **自由意志的选择**——天道崩碎后，世界面临三条路：修复（回到旧秩序）、摧毁（超凡消失）、分散（人人皆可修仙）。炎冬选择第三条路——把天道还给所有人

## 世界观设定

### 渊穹界

天道崩坏，化为漫天诡异。天上飞着蒸汽飞艇和齿轮天穹，地下爬着触手怪物和畸变体。修仙即修诡——正道把血肉换成冰冷的齿轮，魔道把灵魂喂给深渊的恶鬼。凡人靠蒸汽机械抵御诡异，但过度依赖机械也会产生新的畸变。这是一个疯狂的世界：正道比魔道更黑暗，秩序比混乱更残忍。

#### 赛博朋克氛围要素

渊城是一座垂直分层的巨型城市，蒸汽管道像血管一样爬满每一面墙壁：

- **下层区**：永远不见天日。头顶是上城区的铜底板，蒸汽管道从缝隙中漏下滚烫的水汽。霓虹灯牌用诡异源质发光——绿莹莹的光映着湿漉漉的石板路。空气里永远弥漫着铁锈味、煤烟味、和一丝若有若无的腐烂气息。巷子里堆满了废弃的机械零件和没人收的尸体
- **上城区**：干净、整齐、冰冷。铜制建筑反射着齿轮天穹的光芒。街道上巡逻的蒸汽傀儡发出规律的咔嗒声。空气被灵气过滤器净化过——闻起来像金属。凡人走在路上低着头，不敢看灵械修习者的铜色义肢
- **齿轮天穹**：渊城上空的巨大齿轮结构，由道庭维护。齿轮缓慢转动时发出低沉的嗡鸣声，像一头沉睡的巨兽在呼吸。齿轮间隙中偶尔能看到蒸汽飞艇的影子掠过
- **蒸汽管道网络**：全城的血管。粗的如水桶，细的如手指。管道表面刻满灵气抽取符文——路过时能感到体内真气被微微抽走。管道在战斗中可被操控（灵械修习者技能），是环境战术的核心要素

### 能量基础：真气与灵气

- **真气**：天地间最基础的生命能量，存在于万物之中。凡人体内亦有微弱真气，但无法主动运用
- **灵气**：真气经修炼提炼后的高级形态，是灵械修仙的能量来源。道庭通过蒸汽机械从凡人和天地中抽取灵气
- **源质**：诡异携带的腐蚀性能量，是诡术士修炼的燃料。本质是被天道崩坏污染的真气
- 三者同源异流：真气→灵气（正道提炼）、真气→源质（天道崩坏污染）

### 力量体系

#### 正道——灵械修仙
- 靠植入蒸汽机械抽取灵气修炼
- 境界：凡械 → 铜械 → 银械 → 金械 → 天械 → 神械
- 越强机械替换率越高
- 终极追求：**机械飞升**——将全部血肉替换为蒸汽机械，以灵气驱动永恒运转，成为"无情神明"
- 道庭宣称机械飞升是"超脱生死"，实际是失去所有人性——不老、不惧、不悲、不悯
- 关键词：秩序、压抑、非人化、机械飞升

#### 魔道——诡术士
- 吞噬诡异源质修仙
- 境界：染诡 → 驭诡 → 融诡 → 化诡 → 归诡 → 不可名状
- 力量强大但极易畸变失控
- 终极追求：彻底异化，与诡异融为一体，成为"不可名状"的存在
- 诡修会认为异化即升华、疯狂即自由——但最终沦为没有自我意识的怪物
- 关键词：自由、疯狂、异化

#### 深渊邪神

- 深渊最深处沉睡的存在，被称为"深渊邪神"或"深渊之主"
- 非个体诡异，而是深渊本身——整片深渊在"呼吸"，是一只沉睡的超巨型诡异
- 天道崩坏的原爆点就在深渊核心
- 诡修会会首靠吞噬深渊邪神的一小部分获得不可名状境界
- 深渊邪神若完全苏醒，将吞噬整个渊穹界——它是天道崩坏后世界面临的终极威胁

#### 主角特异——械诡双修
- 系统允许在灵械修仙与诡术士之间切换
- 切换消耗体力，休息可恢复，无永久代价
- 终极形态：两重身份融合，械诡一体

### 核心规则
1. **天道崩坏**：原天道已碎，碎片散落为各种诡异
2. **修仙即修诡**：无论正道魔道，修炼的本质都是接触诡异源质
3. **凡人如蚁**：没有修炼资源就是诡异的食物和正道的耗材
4. **净化税加码**：道庭不断抬高净化税，本质是在"喂养"高层机械神仙

### 核动力科技

道庭最高机密——**核动力阵法**。普通灵械靠蒸汽驱动，但道庭核心层掌握了一种远古技术：将灵气压缩到极限后引发"核动力反应"，释放出远超蒸汽万倍的能量。核动力阵法是道庭统治渊穹界的根基，也是"机械飞升"的终极能量来源。

- **核动力核心**：道庭之主"太上"体内的灵气转化炉就是核动力阵法的终极形态——以凡人灵气为燃料，驱动永恒运转
- **核动力义肢**：道庭最高层（天械级以上）才有的配置，普通蒸汽义肢与之相比如同蜡烛比太阳
- **禁忌知识**：核动力阵法的原理被道庭列为最高机密，外泄者诛九族。因为其本质是——用凡人的生命能量驱动机器

#### 经济压迫逻辑

- **炎冬的净化税60灵石/7天**：相当于凡人1年以上收入，灵械修习者3-4个月收入。对"破落商人之子"而言是天文数字——这就是"死线"的压迫感来源
- **凡人月入3-5灵石 vs 净化税5灵石/月**：凡人收入几乎全部交税，勉强糊口。一旦加码就活不下去
- **灵械修习者月入15-25 vs 净化税15-20**：同样被压到极限，没有积蓄空间
- **黑市是唯一出路**：合法收入永远不够，只有灰色地带才能挣到足够的灵石——这是底层人涌入黑市的根本原因，也是炎冬入黑市的必然性

### 命名规范
- **装备命名**：赛博朋克材质词+仙侠功能词，如"铜骨臂甲""矿魂护甲""暗声哨"。避免俗名（"铁皮""破铜"等）
- **功法命名**：仙侠命名法，意境优先，如《噬源诀》《岩魄锤法》《逆鸣诀》。避免武侠风（"锤法"→"锤法"可保留但搭配"魄""魂"等仙侠词）
- **诡异命名**：行为/外观特征词，如"食残诡""管蛭诡""铜骨尸""织梦蛛""噬面者"。避免通用名

## 系统设定：诡枢录

### 基本规则
- **系统不说话**——没有AI人格，没有"叮"的提示音，不跟主角交流。只以面板形式显示信息
- **系统没有声音**——面板文字直接浮现于意识，不经过听觉。绝对不写"天道说""系统提示道"，只写"面板显示""面板弹出"
- **面板文字有性格但绝不评价**——面板的"性格"只体现在警告/建议栏目的措辞中（简洁冷硬，偶尔讽刺），绝不出现在任务完成、奖励、状态等客观数据栏目。具体划界如下：
  - ✅ **允许讽刺的栏目**：警告、建议、备注——这些是系统对宿主安全的提示，讽刺感=冷幽默，如 `"警告：宿主正在做蠢事。建议：停止。"`或`"提示：逃跑也是一种战术，虽然不太体面。"`
  - ❌ **绝对不允许性格的栏目**：奖励列表、境界进度、击杀计数、任务完成提示、系统进化——这些是客观数据，必须冷静精确，如 `【诡术经验+200】`而非`【辛苦了，给你点奖励】`
  - ❌ **绝对不评价**：面板不说"好""不错""明智"等价值判断。炎冬打得好不好，由评级数字说话，不由面板文字说话
- **杀诡异=爆奖励**——击杀诡异后系统自动结算，奖励包括：境界提升、装备、功法、丹药、材料等
- **贡献评级**——根据战斗表现评级（D/C/B/A/S/SS/SSS），评级越高奖励越丰厚
- **越级击杀加成**——杀比自己当前境界高的诡异，评级和奖励翻倍
- **炎冬自己解读面板**——面板只给数据，推理留给主角和读者。这是"智商碾压爽点"的核心来源
- **面板升级=角色成长**——系统从简陋面板→多功能面板→融合商店→最终进化，面板本身就是一条成长线

### 系统推动力机制

**倒计时**：系统在关键节点弹出倒计时，制造紧迫感。首次出现在第1章（寄生体觉醒7天），贯穿全书每5-8章至少一次。

**沉默建议**：系统在关键时刻弹出"建议"，但不替宿主做决定。建议只出现在改变命运的转折点（Ch1救命、Ch10双面模式、Ch21义肢抉择、Ch52绝境突破、Ch151心魔之战）。

**惊喜彩蛋**：不定期弹出意外奖励，让读者产生"下次会爆什么"的期待。首次出现在第5章（首次击杀彩蛋）。

```
✦ 诡术经验+800
  →境界提升！染诡→驭诡！
✦ 装备：矿魂护甲（驭诡级）
  效果：抵御精神攻击30%
✦ 功法：《岩魄锤法》
  效果：地脉环境伤害+50%
✦ 丹药：破境丹×1
  效果：下次突破成功率+30%
✦ 特殊：天道碎片·柒（任务物品）
```

### 爽点设计——奖励开箱感

1. **评级惊喜**——读者跟主角一起紧张等待评级，S级以上触发"金色面板"
2. **越级加成**——主角每次越级击杀都让读者期待奖励翻倍
3. **装备效果**——每件装备都有明确的战斗效果，下一次战斗直接体现
4. **隐藏奖励**——偶尔触发"隐藏任务"或"暴击奖励"，给读者意外惊喜
5. **境界飞跃**——奖励直接推动境界提升，让主角肉眼可见地变强

### 结算面板写作规范

#### 标准结算面板格式
```
击杀结算

目标：[诡异名]（[等级]诡异）
贡献评级：[等级]
（[评级因素1+因素2+...]）

【奖励】
✦ [类型]：[具体奖励]
  效果：[具体效果]
✦ [类型]：[具体奖励]
  效果：[具体效果]
```

#### 结算面板叙事节奏（每次结算必须遵循）
1. **战斗结束 → 短暂沉默（2-3句环境描写制造悬念）**：诡异倒下，周围恢复安静，炎冬喘着气——然后面板浮现
2. **先显示评级**：读者跟主角一起紧张等待评级结果，评级越高标记越醒目（D-C级无标记，S级★，SS级★★，SSS级★★★）
3. **逐条展示奖励**：每条奖励后跟1-2句炎冬的内心反应或思考（"这东西……能让我在下一次战斗中……"）
4. **总评**：炎冬对奖励的规划思考，自然过渡到下一场景

#### 评级等级与标记对应

| 评级 | 标记 | 触发条件 |
|------|------|----------|
| D-C级 | 无 | 低阶诡异，常规击杀 |
| B-A级 | 无 | 中阶诡异或低阶但有战术配合 |
| S级 | ★ | 越级击杀+环境影响利用+独立击杀 |
| SS级 | ★★ | 越两级击杀+极限反杀 |
| SSS级 | ★★★ | 越两级+濒死反杀+紧急任务+全书级里程碑 |

## 主要势力

### 太上蒸汽道庭（正道魁首）
- 以蒸汽科技镇压诡异
- 表面神圣，实则高层已半机械化
- 冷酷无情，视凡人如草芥
- 核心理念：秩序至上，个体可弃

### 极乐诡修会（魔道势力）
- 崇拜深渊诡异，热衷血祭与畸变
- 成员多为疯子
- 认为彻底异化才是成仙
- 核心理念：异化即升华，疯狂即自由

### 黑市商盟（灰道势力）
- 游走于正邪之间
- 贩卖诡异材料和禁忌机械
- 唯利是图
- 主角初始发家之地
- 核心理念：利益至上，规则可通融

### 天枢巡检司（官方执法）
- 专门猎杀失控的诡术士和狂暴机械
- 手段极其残酷
- 表面维护秩序，实则高层与道庭勾连
- 核心理念：净化一切异端

|------|------|

| 性别 | 男 |
| 年龄 | 20岁（开局） |

| 核心信条 | "比诡异更诡异，比疯子更疯子"——在这个疯狂的世界，只有比敌人更疯狂才能活到最后 |

### 双重身份

| 身份 | 表面 | 实际 |
|------|------|------|
| 灵械修习者 | 合法修炼者，通过巡检司认证 | 用来白天行走、通过检查、获取合法资源 |
| 诡术士 | 被追杀的魔道修炼者 | 夜间猎杀诡异、获取系统奖励、真正变强的途径 |

### 穿越者优势

炎冬是穿越者，前世记忆带来以下具体优势（**必须在写作中体现**）：

1. **博弈思维**：前世社会经验让他擅长谈判、信息差利用、利益计算。面对NPC式的土著，他的思维维度更高
2. **系统直觉**：作为穿越者，他对"系统"的概念有天然理解——面板弹出时他不恐惧，而是立刻开始分析规则
3. **心理素质**：穿越者的"局外人"视角让他在面对恐怖场景时比土著更冷静——不是不怕，而是能压制恐惧
4. **知识局限**：前世知识在修仙世界有边界——他懂博弈但不懂阵法，懂心理但不懂源质。面板弥补了这个缺口

### 无女主规则

**本书无女主，无恋爱线，无后宫。** 所有女性角色（小桃、红蛛、小翠、蛛后、铜铃婆等）都有独立弧线和独立动机，不是男主的附属品。她们可以是盟友、对手、被保护的对象，但绝不是"等待被拯救的公主"或"暗恋男主的花瓶"。角色之间的关系是利益合作、信任建立、理念碰撞，不是暧昧。

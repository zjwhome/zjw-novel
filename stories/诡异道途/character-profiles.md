### 太上蒸汽道庭（正道魁首）
- 以蒸汽科技镇压诡异
- 表面神圣，实则高层已半机械化
- 冷酷无情，视凡人如草芥
- 核心理念：秩序至上，个体可弃

### 极乐诡修会（魔道势力）

表面是崇拜深渊诡异的疯狂组织，内部是一个完整的社会——有家庭、有日常、有温情、有互助，只是这些被疯狂的信仰包裹着。不是所有人都是狂热者，很多人只是走投无路。

#### 信仰体系

| 概念 | 诡修会解释 | 实际 |
|------|-----------|------|
| 异化即升华 | 身体畸变是进化，源质结晶是神赐 | 碎片意识侵蚀的副产品 |
| 疯狂即自由 | 放弃理性才能触碰真实 | 精神力崩溃后的自我合理化 |
| 深渊即母体 | 深渊是万物起源，回归深渊是回家 | 深渊是沉睡的超巨型诡异 |
| 碎片即神 | 碎片·伍是"神"的化身 | 碎片在等待真正的持有者 |

信徒并非天生疯狂——他们中很多人先失去希望，再被信仰填补。信仰给了他们"意义"，代价是理性。

#### 内部结构

| 层级 | 人数 | 特征 |
|------|------|------|
| 会首 | 1人 | 不可名状级，碎片吞噬者，300年来靠吞噬深渊邪神力量维持 |
| 长老派 | 3人（化诡级） | 务实派，与商盟有秘密交易，追求碎片力量而非纯粹疯狂 |
| 激进派 | 12人（融诡级） | 狂热者，主动追求畸变，身体已半非人化 |
| 深渊司祭 | 1-2人（归诡级） | 深渊守卫，全身源质结晶化，意识已半融入深渊 |
| 普通信徒 | 50+人（铜械级以下） | 成分复杂：走投无路的凡人、被道庭追杀的逃亡者、家人被诡异感染的绝望者、真正的狂热者 |

#### 日常生活

诡修会圣殿不是地狱——至少不完全是。

- **住所**：圣殿外围的石室，每间住2-4人。条件简陋但有蒸汽供暖。信徒之间会互相分享源质结晶取暖
- **食物**：诡异肉为主（煮熟的低阶诡异，灰绿色，腐甜气息），偶尔有从外面走私进来的普通粮食。食堂是信徒社交的主要场所
- **互助**：新信徒由老信徒带教——如何控制源质、如何避免畸变失控、如何在仪式中活下来。这种"师徒关系"是诡修会内部最接近温情的东西
- **家庭**：部分信徒有配偶和孩子，住在圣殿外围的"家属区"。孩子不上缴源质，但从小被教育"深渊是母亲"
- **经济**：每月上缴50灵石源质换取庇护。交不起的当祭品——这是诡修会的"净化税"，和道庭本质相同

#### 普通信徒画像

不是所有信徒都是疯子。典型普通信徒：

| 类型 | 动机 | 占比 | 特征 |
|------|------|------|------|
| 逃亡者 | 被道庭/巡检司追杀，无处可去 | 约30% | 低调、谨慎、只想活命 |
| 绝望者 | 家人被诡异感染，道庭要"净化"，诡修会说"能治" | 约25% | 为家人什么都愿意做 |
| 被裹挟者 | 生活在诡修会势力范围，不加入就死 | 约20% | 被动、沉默、随大流 |
| 狂热者 | 真心信仰异化即升华 | 约15% | 主动追求畸变，是诡修会的"模范信徒" |
| 利益者 | 利用诡修会资源修炼/做生意 | 约10% | 务实、两面派、谁赢帮谁 |

炎冬杀穿诡修会时，杀的不只是狂热者——还有逃亡者、绝望者、被裹挟者。这是他必须面对的道德灰度。

#### 与道庭的镜像关系

道庭和诡修会是同一种剥削的两种面孔：

| 对比项 | 道庭 | 诡修会 |
|--------|------|--------|
| 对凡人 | 净化税→灵气电池 | 源质上缴→交不起当祭品 |
| 对信徒/修习者 | 服从→晋升 | 服从→庇护 |
| 核心谎言 | "净化保护凡人" | "异化即升华" |
| 真相 | 用凡人灵气维持道庭动力 | 用信徒源质喂养碎片/深渊 |
| 内部温情 | 巡检司同僚关系 | 信徒师徒/家庭关系 |

两者都不是纯粹的恶——都有普通人在制度中挣扎求存。

### 黑市商盟（灰道势力）
- 游走于正邪之间
- 贩卖诡异材料和禁忌机械
- 唯利是图
- 主角初始发家之地
- 核心理念：利益至上，规则可通融

### 天枢巡检司（官方执法）

专门猎杀失控的诡术士和狂暴机械，手段极其残酷。表面维护秩序，实则高层与道庭勾连。核心理念：净化一切异端。

#### 规模与编制

| 项目 | 内容 |
|------|------|
| 总人数 | 约3000人（渊城及周边辖区） |
| 巡检卫 | 约2400人。普通士兵，凡械/铜械级，配蒸汽长枪+鉴诡仪。负责巡逻、抓捕、押送 |
| 一级巡检 | 约300人。铜械级，可带队巡逻，无净化处置权 |
| 二级巡检 | 约150人。铜械级精英，可执行净化行动，处置"疑似感染"需报批 |
| 三级巡检 | 约80人。银械级，可带队执行净化行动，对"确认感染"者有当场处置权（陆沉即三级巡检） |
| 巡检使 | 约40人。银械级精英，管辖片区，可审批二级巡检的净化报备 |
| 巡检统领 | 约8人。金械级，管辖大区，重大净化行动需道庭审批 |
| 巡检司主 | 1人。天械级，由道庭直接任命，听命于道庭 |

#### 管辖范围

- **渊城全域**：上城区（高频巡逻，每日3次）、下城区（低频巡逻，每周2次，但净化行动集中于此）
- **城外缓冲区**：废矿、荒野、废弃工场。巡检司外派小队定期巡猎（每旬1次）
- **无管辖权区域**：地下废墟/暗城（巡检司不承认其存在，但也不敢深入）

#### 与道庭的隶属关系

- **名义上**：巡检司是独立执法机构，负责渊城治安和诡异净化
- **实际上**：巡检司主由道庭直接任命，巡检统领中有3人是道庭安插的眼线
- **净化税代征**：巡检司负责代征净化税，全额上缴道庭。代征过程中巡检司截留5%作为"行政费用"
- **重大行动审批**：大规模净化行动（单次处置50人以上）需报道庭审批。日常小规模净化由巡检使/三级巡检自行决定
- **信息管控**：巡检司定期向道庭汇报诡异分布、诡术士活动、凡人异动。道庭通过巡检司掌控渊城基层

#### 净化权限分级

| 净化对象 | 鉴诡仪标记 | 处置权 | 审批要求 |
|----------|-----------|--------|---------|
| 确认感染（红色） | 红色 | 三级巡检可当场处置 | 无需审批，事后报备即可 |
| 疑似感染（黄色） | 黄色 | 二级巡检需报批后处置 | 巡检使审批。紧急情况可"先处置后补报"——实践中被滥用 |
| 轻微异常（绿色偏黄） | 绿色（微弱波动） | 无处置权 | 带回"净化观察"（隔离审查），观察期7天。观察期内若恶化为黄色则按疑似感染处置 |
| 正常（绿色） | 绿色 | 无处置权 | 不得触碰 |

**净化行动流程**：巡检司侦测到某区域诡异浓度升高→启动鉴诡仪扫描该区域所有居民→按标记分级处置→"疑似感染"者被带走送"净化观察所"→"确认感染"者当场处置或押送净化所→净化税由巡检司代征

**权限滥用**：鉴诡仪灵敏度可调——调高灵敏度会让"绿色偏黄"变成"黄色"，扩大净化范围。巡检司在净化税加码后频繁调高灵敏度，以"疑似感染"为名带走更多凡人。这就是Ch60/62/86中母亲/少年被带走的制度根源——他们的鉴诡仪标记从绿色被人为调成了黄色

#### 铜面特殊地位

- 金械级但从不展示实力，巡检司内部无人知道他的真实境界
- 不参与净化行动，只在走廊/暗处观察
- 面板扫描：体内有微量诡异残留但被某种技术压制——净化实验幸存者的特征
- 直接向巡检司主汇报，但汇报内容不详

#### 道庭内部视角设计

道庭不是单纯的"反派"——它是制度性恶的载体。通过内部角色POV展现"服从命令的普通人"，让攻打道庭不是简单的正邪对决。

| 章节 | POV角色 | 视角内容 | 叙事目的 |
|------|---------|---------|---------|
| Ch71 | 陆沉 | 巡检司值房：净化报告=日常文书工作，指标化管理，同事盖章打哈欠，巡检使审计划时手边放糕点 | 制度性恶的日常化——恶不是疯子做的，是正常人按流程做的 |
| Ch225 | 周小满（铜械级修习者） | 19岁下层区出身，每月寄3灵石回家，不知道攻城原因，只知"守住有功勋" | 道庭守卫不是坏人，只是服从命令的普通人 |
| Ch229 | 赵铜柱（守卫队长） | 站岗八年不知管道里流的是什么，灵气光点飘到脸上才明白——像人的体温 | 真相冲击：他们一直在保护的东西是什么？ |

核心设计：道庭内部视角不改变主线剧情，只增加道德灰度——读者在攻打道庭时会想"这些守卫也是受害者"。

### 炎冬

| 项目 | 内容 |
|------|------|
| 姓名 | 炎冬 |
| 性别 | 男 |
| 年龄 | 20岁（开局） |
| 身份 | 破落商人之子 |
| 核心特质 | 狡诈多谋、杀伐果断、扮猪吃虎 |
| 核心动机 | 杀穿诡异，逆天改命，活得自由 |
| 核心信条 | "比诡异更诡异，比疯子更疯子"——在这个疯狂的世界，只有比敌人更疯狂才能活到最后 |

### 双重身份

| 身份 | 表面 | 实际 |
|------|------|------|
| 灵械修习者 | 合法修炼者，通过巡检司认证 | 用来白天行走、通过检查、获取合法资源 |
| 诡术士 | 被追杀的魔道修炼者 | 夜间猎杀诡异、获取系统奖励、真正变强的途径 |

### 穿越者优势

炎冬是穿越者，前世记忆带来以下具体优势（**必须在写作中体现**）：

1. **博弈思维**：前世社会经验让他擅长谈判、信息差利用、利益计算。面对NPC式的土著，他的思维维度更高
2. **系统直觉**：作为穿越者，他对"系统"的概念有天然理解——面板弹出时他不恐惧，而是立刻开始分析规则
3. **心理素质**：穿越者的"局外人"视角让他在面对恐怖场景时比土著更冷静——不是不怕，而是能压制恐惧
4. **知识局限**：前世知识在修仙世界有边界——他懂博弈但不懂阵法，懂心理但不懂源质。面板弥补了这个缺口
5. **独有能力**：前世现代知识在修仙世界的降维打击——合同契约精神（Ch10）、流体力学工程思维（Ch95）、运筹学系统分析（Ch199）。土著没有这些概念，炎冬的信息维度比他们高一层

### 穿越原因（渐进式揭示，保留悬念）

炎冬的穿越不是偶然——是天道崩碎前的意志在绝望中向"世界之外"伸出的手。三处渐进式揭示：

1. **Ch48碎片共振**：面板隐藏信息——"宿主意识来源：异常。与天道碎片存在时间共振。"暗示穿越与天道有关，但不解释
2. **Ch172天道真相**：面板揭示三个容器的意识来源——前两个是渊穹界原住民（失败/被吞噬），第三个（炎冬）意识来自"世界之外"。天道崩碎前的意志将搜索范围扩展到碎片时间共振范围之外，在所有可能的世界中找到了一个"外部视角"
3. **Ch249终章**：面板最后回答"为什么是我"——"你不是被'选中'的，你是被'找到'的。也许是因为你在那个世界里……也在寻找一个'不同的活法'。但：这只是推测。系统无法验证。"

**核心设计**：不彻底解释穿越原因。天道为什么选择"外部视角"、炎冬前世的什么特质与碎片共振、系统为什么无法验证——这些留白让读者自己填充。穿越不是金手指的来源（金手指是诡枢录），而是"视角"的来源——一个从"外面"看这个世界的人，才能看到"里面"的人看不到的出路

### 穿越者弱点——NPC思维→真实共情

炎冬的穿越者身份不仅是优势，也是弱点。前世打游戏的本能让他在初期把这个世界的人当"NPC"——面板扫描到数据但不产生共情。这个弱点贯穿全书，形成一条完整的转变弧线：

| 阶段 | 章节 | 表现 | 叙事目的 |
|------|------|------|---------|
| NPC思维 | Ch2 | 面板扫描到马六体内诡异感染，选择不说——"说了对我没好处" | 展示穿越者的冷酷理性——不是坏，是把人当数据 |
| 第一道裂缝 | Ch20 | 搜捕日听到惨叫，面摊老头冷面让他产生"这个世界的人不是NPC"的念头，但立刻压下去 | 冲突萌芽——生存本能压过共情 |
| NPC壁垒被打破 | Ch59 | 小桃塞馒头——没有任务弹出、没有奖励，只是善良。炎冬发现自己在想她的话，不安 | 第一次被"NPC的善良"打动 |
| 主动保护 | Ch96 | 蚀骨决战——面板建议撤退（15%胜率），但小桃喊"快跑"时炎冬没有跑 | 从"数据"到"我要保护的人" |
| 真正共情 | Ch133 | 迁移名单上面摊老头/马六/老妇人——面板标记"低于净化税阈值"，炎冬不再忽略 | 不再压下去了——他们不是数据，是人 |
| 共情完成 | Ch228 | 电池舱中小桃——面板数据炎冬没看，蹲下来看她的眼睛。想起Ch2/Ch20/Ch59。愤怒而非愧疚 | 不再是"局外人"——他已经是这个世界的人 |
| 终章 | Ch248 | 小桃笑了——想起前世按空格跳过NPC台词，想起Ch2只看到"数据点"的自己 | 穿越者弧线完成——从"玩家"到"人" |

**核心设计**：穿越者弧线不是"善良觉醒"，而是"从把世界当游戏到把世界当真"。炎冬不是从坏人变好人，而是从"局外人"变成"这个世界的人"。

### 无女主规则

**本书无女主，无恋爱线，无后宫。** 所有女性角色（小桃、红蛛、小翠、蛛后、铜铃婆等）都有独立弧线和独立动机，不是男主的附属品。她们可以是盟友、对手、被保护的对象，但绝不是"等待被拯救的公主"或"暗恋男主的花瓶"。角色之间的关系是利益合作、信任建立、理念碰撞，不是暧昧。

## 女性角色独立弧线

本书无女主、无恋爱线。所有女性角色都有独立动机和完整弧线，不是男主的附属品。

| 角色 | 独立动机 | 弧线阶段 | 关键转折 | 独立性体现 |

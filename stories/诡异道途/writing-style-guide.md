# 《诡异道途》写作风格指南

> 本文件规范小说正文的写作标准，确保风格一致、去AI味、符合番茄平台读者习惯。
> **版本：v3.0 | 更新日期：2026-06-16**

---

## 一、叙事视角

### 主视角：第三人称有限视角（炎冬POV）
- 以炎冬的感知和思维为主，读者只能看到炎冬看到的、想到的
- 不写炎冬不在场时其他角色的内心活动（除非切换POV）
- 面板文字属于炎冬意识的一部分，不算全知信息

### POV切换规则
- **常规章节**：不切换POV，全程炎冬视角
- **特殊章节**：允许切换1次，需满足以下条件之一：
  - 道庭内部视角（Ch71陆沉/Ch225周小满/Ch229赵铜柱）——展示制度性恶的日常化
  - 关键反派视角（Ch207沈九渊碎片侵蚀）——展示反派人性面
- **切换格式**：用`---`分隔，切换前用一段环境描写过渡
- **切换限制**：每卷最多2次POV切换，全书不超过10次

## 二、对话风格

### 基本原则
- **简洁有力**：每句对话不超过20字，能3个字说完的不用5个字
- **口语化**：不要文言文，不要书面语，像真人说话
- **个性化**：每个角色有自己的说话方式，通过对话能认出是谁

### 各角色语言特征

| 角色 | 说话风格 | 示例 |
|------|---------|------|
| 炎冬 | 简短、冷静、偶尔讽刺。内心戏多但嘴上少 | "以前是。"（碾压后一句话） |
| 钱三 | 谨慎、绕弯子、重利但讲义 | "有些事情，他活着的时候跟我说过。" |
| 陆沉 | 沉默、压抑、酒后吐真言 | "我今天放走了一个。明天他们会让我补上。" |
| 沈九渊 | 冷静、精准、不带感情 | "你不是在藏，就是在骗。" |
| 幽烛 | 轻柔、疯狂内容用平静语气说 | "我们不需要你做什么。只需要你……偶尔看看那边的窗户。" |
| 面摊老头 | 极少说话，说了就是关键 | "吃吧，上城区的面贵。" |
| 小桃 | 直接、不说漂亮话 | "你是唯一不嫌弃我们手脏的学员。" |
| 赵铁山 | 教官式简洁、点到为止 | "你藏的东西，藏好。" |
| 铜铃婆 | 信息掮客式、半藏半露 | "信息是要花钱的——不是灵石，是人情。" |

### 对话禁忌
- 不用"他沉声道""她冷笑道""他淡淡说"等AI味描写词
- 不用感叹号堆砌（"！！！"）
- 不用省略号表达深沉（"……"每章最多出现3次）
- 不写角色自言自语解释剧情

## 三、描写密度

### 赛博朋克氛围描写
- **每章至少1处**环境描写，50-100字，融入感官细节（视觉/听觉/嗅觉/触觉）
- **首次出现的场景**：200-300字沉浸式描写
- **重复场景**：30-50字一句话带过（"蒸汽管道嘶嘶作响，和昨天一样"）
- **核心意象**：齿轮天穹、蒸汽管道、霓虹灯牌、铜锈味、源质绿光

### 战斗描写
- **节奏**：短句为主，每句不超过15字。动作→反应→动作→反应
- **面板穿插**：战斗中面板弹出不超过3次，每次不超过2行
- **感官细节**：每次战斗至少1个感官细节（骨头碎裂声/源质腐蚀气味/蒸汽烫伤感）
- **手抖描写**：涉及右手的战斗必须体现颤抖后遗症（握力不稳/需左手辅助/武器偏移）

### 面板文字
- **格式**：用反引号或缩进区分，与正文明确分隔
- **措辞**：冷硬、简洁、偶尔讽刺（仅限警告/建议栏目）
- **长度**：D-C级一句话（≤1行），B-A级3-4行，S级8-12行，SS级12-15行，SSS级15-20行
- **绝对禁止**：面板说"好""不错""明智"等价值判断词

### 战斗描写示例（正确写法）
```
矿婴从矿壁上弹出来，速度快得像被弹簧弹射的铁球。
炎冬侧身，右臂铜骨臂甲格挡。撞击声闷得像敲烂木头。源质腐蚀从接触点蔓延，臂甲表面冒出绿烟。
面板弹出——
【矿婴 | C+级 | 弱点：强光 | 当前胜率：34%】
三十四。不够。
炎冬退了两步，左手摸到腰间的铜灯。灯油还有大半。前世打FPS的肌肉记忆让他没犹豫——拔栓、甩臂、铜灯砸在矿壁上碎裂，火油溅开，矿道亮如白昼。
矿婴尖叫。那声音不是从嘴里出来的，是从全身每一个溃烂的伤口里同时挤出来的。
炎冬趁它缩成一团的三秒钟冲上去，铜骨臂甲全力砸在它头颅上。一下。两下。第三下时骨头碎裂的触感从臂甲传到手臂。
面板弹出——
【击杀：矿婴 | 等级：C+ | 结算：S级（越级击杀+1）| 奖励：源质×340】
```

**要点**：短句为主→面板穿插不多于3次→感官细节（撞击声/绿烟/骨头碎裂触感）→穿越者思维只用一句话点明

### 面板反应示例（正确写法）
```
面板弹出——
【警告：寄生体活性↑30% | 倒计时修正：4天 | 备注：时间不够了】
炎冬盯着面板上那个"4"，手指无意识地攥紧了铜骨臂甲的关节。
四天。之前是七天，现在是四天。
他没有慌。前世做项目经理时见过更离谱的deadpne变更——需求方凌晨三点改需求，第二天早上要上线。区别是那次丢的是工作，这次丢的是命。
"走。"炎冬站起来，"去废矿。"
```

**要点**：面板弹出→炎冬有具体的身体反应（攥紧关节）→穿越者思维用前世经历类比（项目经理deadline）→用行动收尾而非继续内心独白

### 赛博朋克氛围描写示例（正确写法）
```
下层区的巷子窄得两个人并肩走都嫌挤。蒸汽管道从头顶爬过，粗的有水桶那么粗，细的像手指，表面刻满了灵气抽取符文。路过时能感觉到体内的灵气被微微抽走——像有人用吸管在你血管里轻轻吸了一口。
霓虹灯牌用诡异源质发光，绿莹莹的光映着湿漉漉的石板路。空气里弥漫着铁锈味、煤烟味、和一丝若有若无的腐烂气息。巷子深处堆满了废弃的机械零件，零件缝隙里长出了暗紫色的菌丝——那是源质污染的痕迹。
```

**要点**：感官五感全覆盖（视觉/触觉/嗅觉）→用比喻让抽象概念具象化（"像有人用吸管在你血管里轻轻吸了一口"）→细节有世界观信息量（源质污染菌丝）

## 四、内心独白

### 格式区分
- **面板信息**：用面板格式呈现，是"数据"
- **炎冬思考**：直接写在正文中的心理活动，不用引号不用斜体，自然融入叙事
- **穿越者思维**：当前世知识被运用时，用1-2句话点明，不展开解释

### 示例
```
面板弹出——
【目标：矿婴 | 危险等级：C+ | 弱点：强光】

炎冬看着面板数据，脑子里已经在算：强光，停尸房有铜灯，距离三米，跑过去需要1.2秒。
前世打FPS的肌肉记忆让他没有犹豫。
```

### 禁忌
- 不写"他心想""他暗想""他思索道"等引导词
- 不用斜体表示内心活动（番茄不支持）
- 不写超过3句的连续内心独白——用行动打断

## 五、禁忌词汇与表达

### AI味词汇黑名单
以下词汇/表达在正文中**绝对禁止使用**：

| 禁忌 | 替代 |
|------|------|
| "不禁" | 删掉，直接写动作 |
| "竟然" | 少用，最多每章1次 |
| "居然" | 同上 |
| "仿佛" | 每章最多2次 |
| "宛如""犹如" | 用"像" |
| "顿时""霎时""刹那间" | 用"瞬间"或直接写动作 |
| "缓缓""徐徐" | 用"慢慢"或直接写 |
| "眸子""星眸""凤目" | 用"眼睛""眼" |
| "嘴角微微上扬" | 用"笑了"或具体描写 |
| "嘴角勾起一抹弧度" | 同上 |
| "眼中闪过一丝XXX" | 删掉，用行动表达 |
| "心中暗道" | 删掉，直接写想法 |
| "他沉声道""她冷笑道" | 删掉提示词，直接写对话 |
| "一股XXX的气息扑面而来" | 具体描写气味/温度/质感 |
| "不由自主""情不自禁" | 删掉 |
| "骇人听闻""触目惊心" | 具体描写恐怖场景 |
| "深邃""幽深" | 用"深""黑" |
| "磅礴""浩瀚" | 具体化 |

### 叙述节奏禁忌
- 不连续3段以上纯描写（无动作无对话）
- 不连续5段以上纯对话（无描写无动作）
- 不在战斗中插入超过2句的回忆
- 不在高潮前插入大段背景设定

## 六、章节结构规范

### 标准结构（3000字/章）
1. **开场**（200-400字）：承接上章钩子，快速进入本章核心事件
2. **发展**（1500-2000字）：核心事件展开，含1-2个爽点
3. **高潮/转折**（500-800字）：本章最精彩的场景或信息
4. **收尾+钩子**（200-400字）：章末钩子，逼读者点下一章

### 2+1节奏规则
- 每3章中至少2章有战斗/结算/装逼场景
- 允许1章纯铺垫/日常/信息收集，但必须有微爽点（面板弹出/信息差/打脸）

### 章末钩子
- 必须是7种情绪型钩子之一（危机/反转/选择/悬念/视觉/情感/打脸）
- 信息型钩子（面板弹出任务）不能单独出现，必须搭配情绪型
- 钩子文字不超过3行

### 战斗篇幅标准

| 战斗类型 | 篇幅 | 节奏 | 示例章节 |
|---------|------|------|---------|
| 小型遭遇战 | 300-500字 | 短句密集，3招内结束 | Ch5面纱客、Ch17管蛭诡 |
| 中型Boss战 | 800-1200字 | 试探→反击→高潮→结算 | Ch9矿婴、Ch15铜骨尸 |
| 大型Boss战 | 1500-2500字 | 多阶段，环境利用，面板穿插 | Ch52噬面者、Ch97蚀骨 |
| 终极决战 | 2500-3500字（1整章） | 全力爆发，多回合，史诗感 | Ch242融合体 |
| 团战碾压 | 500-800字 | 境界碾压，一招一个，快节奏 | Ch183天元丹碾压 |

**核心原则**：战斗越重要篇幅越长，但绝不超过1整章。番茄读者要的是"爽"不是"详细"。

### 番茄平台节奏示例

#### 黄金三章节奏（Ch1-3）

```
Ch1（开箱+危机）：停尸房醒来→面板激活→食残诡→铜灯驱散→7天死线
  ↓ 钩子：寄生体7天觉醒倒计时
Ch2（双重绞索）：世界观展示→面摊老头初遇→马六收税→鉴诡仪生死三秒→双重死线
  ↓ 钩子：面板弹出两条死线
Ch3（反转+更大危机）：父亲遗产→源质冲击波装逼→账册真相→纸条被动手脚
  ↓ 钩子：有人在引导他去城西
```

**要点**：每章至少1个爽点+1个钩子，3章内完成"开金手指→展世界观→埋危机"。

#### 日常章节奏（铺垫章）

```
开场（200字）：承接上章，快速进入
微爽点1（300字）：面板弹出日常任务/信息差/小装逼
发展（800字）：剧情推进，人物互动
微爽点2（300字）：面板扫描揭示信息/穿越者思维
收尾（200字）：章末钩子
```

**要点**：铺垫章也必须有2个微爽点，不能纯叙事。

#### 高潮章节奏（卷末爆炸）

```
开场（200字）：紧迫感拉满
战斗（1500字）：多阶段Boss战，面板穿插≤3次
突破（500字）：境界突破仪式感
结算（500字）：SSS级史诗面板
收尾（300字）：碾压+章末钩子
```

**要点**：高潮章的爽点密度是日常章的3倍，每300字至少1个爽感冲击。

## 七、番茄平台合规

### 禁止内容
- 不写性暗示/色情描写
- 不写过度血腥的肢体细节（用侧面描写替代）
- 不写现实政治敏感内容
- 不写宗教敏感内容
- 不用脏话（用"该死""混蛋"等替代）

### 血腥场景处理
- **禁止**：直接描写内脏/断肢/血液喷溅细节
- **允许**：侧面描写（"广场上传来惨叫声，围观人群有人呕吐"）、感官暗示（"空气中弥漫着铁锈味"）、结果描写（"地上多了一滩暗红"）

## 八、术语一致性

### 必须统一的术语
| 术语 | 正确写法 | 禁止写法 |
|------|---------|---------|
| 系统名 | 诡枢录 | 双面诡术系统/面板系统 |
| 世界观 | 赛博朋克 | 蒸汽朋克 |
| 能量1 | 灵气（前期） | 真气（前期禁止用） |
| 能量2 | 源质 | 暗能量/魔气 |
| 正道 | 太上蒸汽道庭/道庭 | 正道/仙门 |
| 魔道 | 极乐诡修会/诡修会 | 魔教/邪教 |
| 主角义肢 | 铜骨臂甲/铜色义肢 | 铁臂/机械手 |
| 境界 | 双生/逆鸣/悖论/熔铸/天诡/补天 | 一阶/二阶/三阶 |

### 面板称呼
- 只写"面板显示""面板弹出""面板浮现"
- 绝对不写"系统说""天道提示""诡枢录道"
